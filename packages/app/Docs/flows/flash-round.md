# Flash Round — how a game runs

The simplest game: rapid-fire questions for the whole class, one at a time,
easiest first. Works on every topic. 2–6 teams, about 5–10 minutes.

## Starting the game

1. From the **Library**, pick any topic and choose **Flash Round**.
2. On the **Game setup** screen, read the *How to play* rules, set the team
   count, names and colours.
3. Press **Start Game** — after the countdown, the first question appears.

## Each question

1. The question fills the screen. Teams race to call out the answer —
   decide your own class rule (hands up, whiteboards, first shout).
2. Press **Reveal answer** to show the answer big on screen.
3. Award the point: tap the team that answered first, or **No one — next**
   if nobody got it. The game moves straight to the next question.
4. The counter in the header shows progress (for example **7 of 20**), and
   questions get gradually harder.

## Ending

After the last question, the final scores screen ranks the teams and marks
the winner. **Back to Library** returns to the topic list; **Exit** in the
header leaves at any time.
