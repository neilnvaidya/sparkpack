# Three in a Row — how a game runs

Territory strategy on a 4×4 grid: answer to claim a square, then line up
three of your colour — across, down or diagonal — to win. Best for 2–4
teams, about 10–15 minutes.

## Starting the game

1. From the **Library**, pick any topic and choose **Three in a Row**.
2. On the **Game setup** screen, read the *How to play* rules, set the team
   count (2–4), names and colours.
3. Press **Start Game** — after the countdown, the grid appears with every
   square face-down.

## Each turn

1. The sidebar highlights whose turn it is. That team taps any face-down
   square on the grid to open its question.
2. Read the question aloud. Judge the answer:
   - **Correct** — the square fills with the team's colour.
   - **Incorrect** — the square stays open for a future turn (with a new
     question swapped in where possible) and passes to the next team.
3. Use **Show answer** if you want to reveal the accepted answer before
   marking.
4. After every claim the game checks for a line automatically — no action
   needed from you.

## Ending

The game ends the instant a team lines up three squares in a row, column or
diagonal — the podium appears straight away. If the grid fills with no
line, the team with the most squares wins. **Back to Library** returns to
the topic list; **End game** finishes early at any time.
