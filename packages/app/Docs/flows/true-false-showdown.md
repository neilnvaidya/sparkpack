# True or False Showdown — how a game runs

Every team plays every statement: commit to TRUE or FALSE before the
reveal, and every right call scores. Great for misconceptions. 2–6 teams,
about 5–10 minutes.

## Starting the game

1. From the **Library**, pick any topic and choose **True or False
   Showdown**.
2. On the **Game setup** screen, read the *How to play* rules, set the team
   count, names and colours.
3. Press **Start Game** — after the countdown, the first statement appears.

## Each statement

1. A statement fills the screen with big **TRUE** and **FALSE** cards below
   it. Each team discusses and commits — thumbs, whiteboards or team cards,
   whatever works for your class.
2. Once every team has committed, press **Reveal**. The correct card lights
   up (with a short explanation when there is one).
3. Tap **every team that called it right** — each tap toggles that team.
4. Press **Next** to bank the points and show the next statement.

## Ending

After the last statement, the final scores screen ranks the teams and marks
the winner. **Back to Library** returns to the topic list; **Exit** in the
header leaves at any time.
