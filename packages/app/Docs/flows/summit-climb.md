# Summit Climb — how a game runs

A difficulty ladder: every team climbs a shared 7-rung mountain, choosing a
safe or risky question each turn. Best for 2–6 teams, about 10–15 minutes.

## Starting the game

1. From the **Library**, pick any topic and choose **Summit Climb**.
2. On the **Game setup** screen, read the *How to play* rules, set the team
   count (2–6), names and colours.
3. Press **Start Game** — after the countdown, the mountain appears with
   every team at Base.

## Each turn

1. The sidebar highlights whose turn it is. That team chooses a path:
   - **Steady** — an easy question. Correct climbs 1 rung; wrong stays put.
   - **Risky** — a hard question. Correct climbs 2 rungs; wrong slips down
     1 rung.
2. Read the question aloud, then judge the answer with **Correct** /
   **Incorrect**. Use **Show answer** first if you want to reveal it.
3. The team's climber chip moves on the mountain and play passes to the
   next team automatically.

## Ending

The first team to reach the **Summit** (rung 7) wins immediately and the
podium appears. If nobody summits within 20 turns, the highest climber
wins. **Back to Library** returns to the topic list; **End game** finishes
early at any time.
